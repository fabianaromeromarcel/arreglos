# Desafío - Arreglos y Objetos

## Descripción

Proyecto desarrollado como parte del módulo **JavaScript para la Web** de Desafío Latam.

El objetivo consiste en crear una página principal y dos páginas adicionales para mostrar propiedades en venta y en alquiler utilizando arreglos de objetos y generación dinámica de contenido mediante JavaScript.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap 5
- Font Awesome

## Funcionalidades

- Visualización de propiedades en venta y alquiler.
- Generación dinámica de tarjetas utilizando `innerHTML`.
- Uso de **Template Literals** para construir el contenido HTML.
- Uso de arreglos de objetos para almacenar la información de las propiedades.
- Implementación de ciclos para recorrer los arreglos.
- Uso de condicionales para mostrar si una propiedad:
  - Permite fumar.
  - Permite mascotas.
- Página principal que muestra las primeras tres propiedades de cada categoría.
- Páginas independientes que muestran la totalidad de las propiedades.
